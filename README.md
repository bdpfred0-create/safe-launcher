# Safe Launcher 🛡️
Um Launcher seguro para Android com **Modo Pânico** instantâneo para ocultação de aplicativos bancários e sensíveis.

## 📱 Recursos Principais (Fase 1 - MVP)
- **Tela Inicial & Gaveta de Aplicativos**: Atua como a tela inicial nativa do Android.
- **Seletor de Apps Sensíveis**: Escolha quais aplicativos (Nubank, Itaú, Bradesco, Mercado Pago, etc.) devem ser protegidos.
- **Botão de Pânico Instantâneo**: Ao ser acionado, remove instantaneamente todos os apps sensíveis da tela inicial e da busca.
- **Modo Seguro protegido por PIN**: Ocultação reversível apenas com a senha cadastrada.
- **GitHub Actions Integrado**: Compilação automática do arquivo `.apk` gratuitamente a cada atualização.

## 🚀 Como gerar e instalar o app no seu celular

1. **Crie um repositório no seu GitHub**:
   - Acesse [github.com/new](https://github.com) e crie um repositório (pode ser Público ou Privado).
2. **Envie este código para o seu repositório**:
   - O GitHub Actions vai rodar automaticamente e compilar o arquivo `.apk` em ~2 minutos.
3. **Baixe o `.apk` no celular**:
   - Vá na aba **Actions** no seu GitHub, abra a última execução, baixe o arquivo `safe-launcher-debug.apk` e instale no seu celular.
4. **Defina como tela inicial**:
   - Nas configurações do seu Android, escolha o **Safe Launcher** como tela de início padrão.
